# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through GitHub:
[Report a vulnerability](https://github.com/clickfwd/yoyo/security/advisories/new).
Do not open a public pull request, and do not describe the problem anywhere public before
a fix is released.

Include the Yoyo version, the steps or code that reproduce the problem, and what an
attacker could do with it.

## Supported versions

Security fixes are released for the latest version only. Update to the latest release
before reporting, and check that the problem still exists there.
